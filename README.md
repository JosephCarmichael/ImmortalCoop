# Immortal Co-op

Play **Tale of Immortal (鬼谷八荒)** together: two to four friends each play their own
character in a shared starting world, share NPC deaths and their consequences, and join
each other's battles with their own builds. Players connect through Steam: no VPN, port
forwarding or IP addresses.

**[Download and instructions → josephcarmichael.github.io/ImmortalCoop](https://josephcarmichael.github.io/ImmortalCoop/)**

- Run **ImmortalCoopSetup.exe** from the [latest release](https://github.com/JosephCarmichael/ImmortalCoop/releases/latest):
  it checks your game, Steam and Windows settings, installs or updates the mod, and can
  send problem reports.
- Everyone in a campaign needs the same version; the installer and the game tell you when
  an update is out.

This is an early test build of an unofficial fan project, not affiliated with or endorsed
by Guigu Studio. Each release lists SHA-256 checksums of its files. This repository holds
the website and releases; the mod's source is developed separately.
