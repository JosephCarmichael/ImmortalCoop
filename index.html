A fan-made mod for Tale of Immortal · 鬼谷八荒

Immortal Co-op Cultivate the same world, together

Two to four friends each play their own character in a shared starting world. When one of you kills an NPC, it dies in everyone's world, and you can jump into each other's battles with your own builds. Players connect through Steam: no VPN, port forwarding or IP addresses.

Install

The installer checks everything that could stop the mod from loading or connecting, explains what to fix, and installs or updates the mod. Run it again any time to update.

  1. DownloadImmortalCoopSetup.exe, from the button above.
  2. Put it in your game folder and run itIn Steam: right-click Tale of Immortal → Manage → Browse local files. (It also finds the game on its own.)
  3. Press InstallThen start the game through Steam. The main menu now has a Multiplayer button.

Windows may warn you that the installer is unrecognized, because it is not code-signed. Choose More info → Run anyway (and Keep if your browser asks). The installer never changes your saves or campaigns, and backs up anything it replaces.

Play together

Everyone needs the same version of the mod; the installer and the game tell you when an update is out.

Host

Main menu → Multiplayer → Host game. Then Invite friends (Steam's friend list) or Copy invite and paste it to your friends in any chat. When everyone is connected, press Start campaign.

Join

Accept the Steam invitation, or open Multiplayer and press Paste invite. Then Join game. Each player needs their own Steam account.

What the installer checks

Each check says what is wrong in plain words, and many have a button that fixes it.

  • The game is found and closed
  • Steam is running and you are signed in
  • Your game version matches the mod
  • The game's mod support (MelonLoader) is present and set up
  • The game's folder name works on your Windows language (the 鬼谷八荒 folder makes modded games quit on English Windows; one click fixes it)
  • No second copy of the mod, and which other code mods could interfere
  • The game folder can be changed
  • Your installed version, and whether a newer one is out

Something went wrong?

Send a problem report: it goes privately to the mod's developer, with the logs needed to find the bug.

In the game

Multiplayer → Report a problem, or press Ctrl+Shift+R anywhere (also in battles). You get a report number to mention to your host.

If the game won't start

Run the installer and press Send logs. If you are offline, the report is saved on your desktop to send by hand.

What a report contains: the mod's, mod loader's and game's recent logs, your game and Windows version, the mods in your game folder and the state of your co-op session. Your Windows user name and session codes are removed. Reports are only visible to the developer and are deleted after 120 days.

Common messages

"The host did not answer through Steam"
The host hasn't pressed Host game yet, or one of you is offline in Steam. Check both, then Join again.
"The session code does not match the host's"
The host gets a new code each time they start the game: copy their new invite.
"Game/mod campaign build mismatch"
Someone has a different version of the game or the mod. Everyone runs the installer to update, and lets Steam update the game.
"Steam is in offline mode"
In Steam: Steam menu → Go Online.
The game closes right after starting
Run the installer: it detects the folder-name problem on English Windows and fixes it.
No Multiplayer button
Run the installer and press Check again; it shows whether the mod loaded when the game last started.
